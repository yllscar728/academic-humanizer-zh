# academic-humanizer-zh

一个面向中文论文、毕业论文、研究报告与 MBA 论文场景的降 AI Codex skill。

它的目标不是把文本改得花哨，而是在保留原意、术语、论证和学术风格的前提下，去除机器生成痕迹，让文字更自然、更像真实作者写作。

## 特点

- 面向中文学术文本，而不是通用文案
- 优先保留术语、数据、结论和论证结构
- 重点处理套话、空泛拔高、模糊归因、机械结构和 AI 高频词
- 兼容 MBA 论文场景，但不强行把所有论文改成 MBA 模板

## 文件结构

```text
academic-humanizer-zh-skill/
├── SKILL.md
└── references/
    └── rewrite-checklist.md
```

## 用法

把这个目录放到你的 Codex skills 目录下，例如：

```text
~/.codex/skills/academic-humanizer-zh/
```

然后在需要时直接提出类似请求：

- “这段论文降一下 AI”
- “把这段摘要改得更像人写的，但别改原意”
- “这个文献综述去下 AI 味，保留术语”

## 适用范围

- 中文论文
- 毕业论文
- MBA 论文
- 研究报告
- 学术摘要、文献综述、问题分析、结论部分

## 不做的事

- 不编造数据、文献、案例
- 不把论文改成口语文或文案
- 不改变原文核心观点和结论
